# Security Policy

## Supported Versions

Security fixes are applied to the `main` branch and released in the latest `dev-marketplace` package version.

## Reporting a Vulnerability

Please **do not** open public GitHub issues for security vulnerabilities (such as path traversal in the CLI, malicious scripts inside skills, or credential leaks).

Instead, report vulnerabilities privately via GitHub Security Advisories:

- https://github.com/kingjethro999/dev-marketplace/security/advisories/new

Include:

- Affected CLI command, script, or skill path
- Minimal reproduction steps or proof of concept
- Suggested mitigation if known

We aim to acknowledge reports within 48 hours and publish a fix promptly once verified.
