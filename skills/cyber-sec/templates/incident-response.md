## Response Phases

### 1. Detection & Analysis (0-30 min)
- [ ] Alert received (Periderm, monitoring, user report, bounty)
- [ ] Classify severity (SEV-1 through SEV-4)
- [ ] Assign Incident Commander
- [ ] Create incident channel (Slack/Teams)
- [ ] Begin evidence collection (logs, memory, disk)
- [ ] Determine scope: systems, data, users affected

### 2. Containment (30 min - 4 hours)
**Short-term:**
- [ ] Isolate affected systems (network segmentation)
- [ ] Revoke compromised credentials
- [ ] Block malicious IPs/domains
- [ ] Enable enhanced monitoring

**Long-term:**
- [ ] Apply patches/workarounds
- [ ] Rotate all potentially compromised secrets
- [ ] Deploy WAF rules
- [ ] Verify containment effectiveness

### 3. Eradication (4-24 hours)
- [ ] Identify root cause (Periderm review, forensic analysis)
- [ ] Remove malware/backdoors
- [ ] Patch vulnerabilities
- [ ] Rebuild compromised systems from clean images
- [ ] Verify no persistence mechanisms remain

### 4. Recovery (24-72 hours)
- [ ] Restore from verified backups
- [ ] Monitor for recurrence (enhanced alerting)
- [ ] Gradual traffic restoration
- [ ] Validate system integrity
- [ ] Update detection rules

### 5. Post-Incident (Within 1 week)
- [ ] Conduct blameless postmortem
- [ ] Document timeline, root cause, impact
- [ ] Identify systemic improvements
- [ ] Update runbooks and detection
- [ ] Share learnings (internal + responsible disclosure if applicable)

## Evidence Handling

| Evidence Type | Collection | Preservation | Chain of Custody |
|---------------|------------|--------------|------------------|
| Logs (app, infra, auth) | Centralized logging | Immutable storage (S3 Object Lock) | Signed hash log |
| Memory dumps | `gcore` / `procdump` | Encrypted, access-controlled | Documented transfer |
| Disk images | `dd` / `ftk imager` | Write-blocked, hashed | Forensic bag |
| Network captures | `tcpdump` / Zeek | PCAPNG with metadata | Sealed container |

## Periderm Integration

Periderm CLI scans run on every PR and in CI:
- **Pre-merge:** Blocks on critical/high findings
- **Scheduled:** Daily full-history scans
- **On-demand:** `periderm review --deep` for incident investigation
- **Evidence:** SARIF output attached to incident record
